Problems Covered

1. Longest Palindromic Substring – Find the longest substring that reads the same forward and backward.
2. Implement Trie – Implement a Trie data structure to efficiently insert, search, and check prefixes of words.
3. Subarray Sum Equals K – Find the number of continuous subarrays whose sum equals a given value.
4. Search in Rotated Sorted Array – Search for a target element in a sorted array that has been rotated.
5. Minimum Window Substring – Find the smallest substring containing all characters of a given target string.
